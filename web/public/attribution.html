Data sources and citations

This independent research demo uses historical Steam review interactions and game metadata collected by the UC San Diego McAuley Lab. It is not affiliated with or endorsed by Valve, Steam, UC San Diego or the dataset authors.

What this demo serves

The application serves saved item model features/factors, a historical game catalog and aggregate statistics. Raw reviews, usernames, profile URLs, user histories and user factors are excluded. Feedback collection is disabled.

A review indicates interaction rather than verified liking. Game metadata is historical and is not a current storefront listing.

Source attribution does not assign a license to the dataset. This is a noncommercial research demonstration.
